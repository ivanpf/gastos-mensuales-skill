# Instrucciones para agentes de IA

Este repo carga los gastos mensuales de varios bancos/billeteras a un Google
Sheets. Para cualquier pedido de cargar, categorizar o resumir movimientos,
seguí el flujo de [SKILL.md](SKILL.md) (el encabezado `name`/`description` de
ese archivo es solo para herramientas que lo usan como skill; el resto es
texto plano válido para cualquier agente).

Antes de empezar, verificá el setup descripto en [SETUP.md](SETUP.md)
(`scripts/service_account.json` y `scripts/.sheet_id` deben existir y no se
suben nunca al repo).
